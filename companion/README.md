# Practice with a result you can check

Begin with the [workbook](PRACTICE-WORKBOOK.md) or the [local resource index](reference/index.html). All examples are fictional. The reference examples and answer keys are authored material; preserve your own attempt before consulting them.

- [First result](first-result/exercise.md): turn a notice into an action card and identify what is not established.
- [Studio worksheet](reference/worksheet.md) and [data](practice/studio-costs.csv): distinguish fixed cost, cost per visit and a tie.
- [Source checklist](reference/source-status-checklist.md) and [reference brief](reference/board-brief.md): inspect complete costs, current evidence and missing terms.
- [Small cost program](cost-lab/README.md): standard-library Python reference with five local tests.
- [Briefing agent](briefing-agent/README.md): candidate OpenAI SDK application with seventeen offline tests and separate reviewer keys. Live model behavior remains untested.

The reader companion download preserves the source-folder structure needed by the workbook and developer examples. Extract it into one directory and run chapter commands from that root. SDK checks were tested with Python 3.12 and the pinned `openai-agents==0.24.0`; the simple cost tool needs only standard-library Python. Extra production scripts may need their documented tools and local fonts. This archive is not an installer.

No real accounts, personal records or vendor contact are needed for the source exercises. Native product features and live provider trials need separate actual access. Local arithmetic, scripted SDK calls and a finished file do not establish reader learning or general model reliability.

Original book artwork and production files are not required for these exercises and are not included in this reader download.

## If a step is unfamiliar

Ask your AI thought partner: “I am stuck on [this step]. I am trying to [my goal]. Explain it using an example from my own job, household or interests. Show one step, wait while I try, then check my understanding.” You can ask for a different example. For command-line exercises, have it explain where the command runs, what it changes and what result to expect before you run it. Use a practice copy.
