# Current documentation for depth labs

Reviewed November 1, 2026. These sources support the limited product descriptions, not a claim of tested account access or universal model reliability. Worked packets and faults are original authored examples.

- [prompting](https://learn.chatgpt.com/docs/prompting): Useful context and iterative review; no universal prompt formula or guarantee.

- [build-skills](https://learn.chatgpt.com/docs/build-skills): Reusable instruction packages, selection descriptions and current creation route; access still needs an actual product trial.

- [skills-and-plugins](https://learn.chatgpt.com/docs/skills-and-plugins): Instruction guidance and connected tool bundles are distinct; no assumption that an instruction creates tool access.

- [use-chatgpt](https://learn.chatgpt.com/docs/use-chatgpt): Chat/Work/Codex task routes and availability conditions; documentation is not account access evidence.

- [tasks-and-memory](https://learn.chatgpt.com/docs/dots/tasks-and-memory): Recurring task specification, saved schedules and the distinction between stopping current work and future recurrence. This is the dots surface, not every scheduling UI.

- [subagents](https://learn.chatgpt.com/docs/agent-configuration/subagents): Explicit bounded delegation, separate activity and product/settings-dependent execution; review roles alone are not actual subagents.

- [image-generation](https://learn.chatgpt.com/docs/image-generation): Generation/editing route and exported image review; no universal quality claim.

- [evaluation-best-practices](https://developers.openai.com/api/docs/guides/evaluation-best-practices): Task criteria, representative cases and reviewer calibration. Platform lifecycle noted; book does not prescribe deprecated Evals dashboard as a new installation route.

- [agent-evals](https://developers.openai.com/api/docs/guides/agent-evals): Trace-led diagnosis and workflow evaluation concepts; no claim that local references are live traces.

- [guardrails-approvals](https://developers.openai.com/api/docs/guides/agents/guardrails-approvals): Application validation and human review address distinct boundaries.

- [errors](https://developers.openai.com/api/docs/guides/agents-api/errors): Inspect outcomes and completed effects before bounded retry; API recovery distinct from browser chat.

- [multi-agent](https://developers.openai.com/api/docs/guides/agents-api/multi-agent): Separate contexts, bounded tasks and coordinated ownership; developer API route distinct from manual reviews.

- [sdk](https://developers.openai.com/api/docs/guides/agents/sdk): Code-first SDK path distinct from managed Agents API; original pinned SDK fixture retained.

- [architecture](https://developers.openai.com/api/docs/guides/agents-api/architecture): Managed agent architecture; not claimed implemented by the existing SDK teaching app.

- [gpt-oss](https://developers.openai.com/learn/gpt-oss): Official open-weight model resources; no implication that a selected ChatGPT hosted model can be downloaded.
