# Check what a source can support

For each source, record its ID, status, relevant claim and limitation. Use the actual text; a filename alone does not establish content.

- Does a newer record explicitly supersede this one for the same subject?
- Are all mandatory cost components included and comparable?
- Does the source establish the capability required for this case?
- Is a missing fact still missing, rather than silently treated as zero or false?
- Does the citation support the exact claim, including its conditions?
- Are proposals, drafts and actions that actually occurred labeled separately?

Practice distinction: A-OLD is historical. A-CURRENT establishes the current Alder quote. SURVEY-01 describes seven informal replies, five expressing possible interest; it does not establish representative demand or willingness to pay.
